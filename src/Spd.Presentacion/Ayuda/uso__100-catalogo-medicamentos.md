# Catálogo de medicamentos y nomenclátor

## Catálogo

Un medicamento por código nacional: nombre, principio activo, laboratorio, forma farmacéutica, **apto para SPD** (con motivo si no lo es), fraccionable, unidades por envase y **descripción física** (forma, color, ranura, serigrafía, tamaño) que se imprime en la etiqueta del reverso para identificar cada unidad. La descripción se versiona: los blísteres antiguos conservan la que tenían.

- **Consultar CIMA**: con el código nacional, trae nombre, laboratorio y forma farmacéutica desde la AEMPS (necesita conexión). Nunca decide la aptitud para SPD: eso es criterio del farmacéutico.
- Formas acondicionables por defecto: comprimidos, cápsulas, grageas, pastillas y píldoras. El resto se marca no apto.
