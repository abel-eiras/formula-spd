Esta versión beta mejora la gestión de tratamientos y envases en custodia e incorpora la actualización desde la aplicación.

- Las listas de Tratamientos y Depósito permiten desplazarse hasta el último medicamento.
- Se pueden registrar varias cajas del mismo medicamento con su propia serie, lote y caducidad. El formulario conserva la selección para facilitar las altas consecutivas.
- Las marcas con el mismo grupo homogéneo informado comparten existencias, conservando la identidad de cada caja y la trazabilidad de la marca utilizada.
- En Inicio, un administrador puede comprobar si hay una versión nueva desde Inicio. Desde esta versión podrá descargarla e instalarla desde la aplicación, con verificación de firma y copia de seguridad previa.

**Primera instalación de esta versión:** las versiones anteriores deben actualizarse manualmente. Haz una copia de seguridad, descarga el paquete de tu sistema y sigue las instrucciones incluidas. Los datos se conservan y la base de datos se actualiza al arrancar.

La aplicación continúa en pruebas. Configura las copias de seguridad y conserva una copia antes de actualizar.
