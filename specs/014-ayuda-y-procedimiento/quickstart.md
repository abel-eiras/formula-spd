# Quickstart — validación de Spec 014

1. Pantalla principal → botón "Ayuda": se abre la ventana con las dos secciones (CA-1400).
2. Abrir la preparación de un paciente y pulsar F1: se abre "Procedimiento → Preparación"; desde la
   verificación, "Procedimiento → Verificación" (CA-1401).
3. Provocar el bloqueo "verificador = elaborador" y pulsar "¿Por qué? (F1)": se abre "El porqué de
   los bloqueos" (CA-1402).
4. Abrir "Documentación y conservación" y revisar el bloque "Antes de preparar" (CA-1403).
5. Buscar "verificador": aparecen la entrada de Uso de Preparación y la de Procedimiento de
   Verificación, con su sección indicada (CA-1404).
